RunningHub 设置
配置 RunningHub API Key 与云端 ComfyUI 工作流。从 RunningHub 工作流页面地址栏获取 Workflow ID，并设置要在画布节点上暴露的参数。
工作流列表
—
配置 Workflow ID 与暴露参数
API Key
在 RunningHub 官网「API 控制台」获取 32 位 API Key，保存后写入 API/.env，页面不会回显完整内容。
工作流
从 RunningHub 工作流页面 URL 获取，例如 #/workflow/1850925505116598274 中的数字部分。目标工作流需先在网页端成功运行过一次。
工作流节点
与 ComfyUI 设置相同：展开节点并勾选要暴露的输入项，将自动填入 nodeId 与 fieldName。
暴露参数
nodeId / fieldName 对应 RunningHub 工作流 API 格式中的节点与字段，将作为工作流调用时的输入参数。
