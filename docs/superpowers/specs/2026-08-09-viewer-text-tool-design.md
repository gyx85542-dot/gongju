# Viewer 画笔文字子工具设计

日期：2026-08-09

## 目标

在图片查看器「画笔」面板下增加「文字」子模式：可在图片上点击打字、多段叠加、移动/缩放、改颜色；确认应用时与笔迹一并烧进新图。

## 决策

- 入口：画笔面板内「画笔 / 文字」切换（非整页第四 Tab）
- 交互：点击空白新建并聚焦输入；点击已有文字选中后可拖移、角点缩放、改色/字号
- 多段文字可共存，一次「确认应用」全部栅格化
- 实现：DOM 文字层叠在显示图上，应用时按原图像素坐标绘制到 canvas

## 行为

- 画笔 ↔ 文字：保留笔迹与文字层
- 离开画笔（进裁剪/宫格）或关闭查看器：清空文字层
- 撤回：文字模式撤回文字状态快照；画笔模式仍撤回笔迹
- 无笔迹且无有效文字时，确认应用提示与现有一致

## 范围

- 主路径：static/index.html + static/studio-media-viewer.js + static/studio-media-viewer.css + i18n
- 不引入第三方画布库；online.html 独立 viewer 本轮可不跟（若时间允许再同步）
